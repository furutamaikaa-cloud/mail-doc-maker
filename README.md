# メール資料メーカー（GitHub Pages 版）

メール（.msg / .eml）や Web 記事などの文章を、見出し・要点カード・図番号付きの資料に整えて、PDF / Word で保存できるツールです。
ファイル1つ（`index.html`）だけで動き、サーバーや API キーは不要で、費用はかかりません。

## AI で組み直す方法（無料）

1. メールや文章を読み込む
2. 「AIが使えないとき：チャットのAIに頼む」→「依頼文をコピー」
3. 「Claudeを開く」で Claude（無料版で可）のチャットを開き、貼り付けて送る
4. 返ってきた回答を全部コピーして、ツールの欄に貼り付け「回答を反映」

依頼文には読み込んだ文章が含まれ、チャットのAIに送られます（画像は送られません）。社外秘の内容を扱うときは、社内のルールで使ってよいAIか確認してください。

## できること / できないこと

| 機能 | GitHub Pages 版 | claude.ai 版 |
|---|---|---|
| .msg / .eml の読み込み、文章・画像の貼り付け | ○ | ○ |
| ペライチ化（見出し・ポイントカード・チェックリスト・入力例の吹き出し） | ○ 元の見出し（■など）と箇条書きをもとに組み立て | ○ AI が内容を読んで構成 |
| AI による要約・見出しの付け直し・図解（ステップ図・比較表・数字・関係図）・画像の説明 | ○ 「チャットのAIに頼む」で、無料版の Claude などに依頼文を貼って回答を貼り戻す | ○ 自動 |
| 縦横・ページ数・色の指定、画像の差し込みと移動 | ○ | ○ |
| PDF / Word 保存、コピー | ○ | ○ |

ツールはメールの内容をブラウザの中だけで処理し、どこにも送信・保存しません（上の手順でチャットのAIに貼り付けた場合を除く）。

## 公開手順（無料）

1. GitHub にログインし、右上の「+」→「New repository」を押す
   - Repository name：例 `mail-doc-maker`
   - **Public** を選ぶ（無料プランで GitHub Pages を使うには公開リポジトリが必要です）
   - 「Create repository」を押す
2. 作成したリポジトリの画面で「uploading an existing file」をクリックし、`index.html`（と、この `README.md`）をドラッグして「Commit changes」を押す
3. リポジトリの「Settings」→ 左メニュー「Pages」を開く
   - Source：**Deploy from a branch**
   - Branch：**main** / **/(root)** を選んで「Save」
4. 1〜2分待つと、同じ画面の上部に公開 URL が表示されます
   `https://<GitHubのユーザー名>.github.io/mail-doc-maker/`

更新するときは、新しい `index.html` を同じ手順でアップロード（上書き）すれば、数分で反映されます。

## 注意

- 公開リポジトリなので、**ツールのファイル自体は誰でも見られます**。ツールには社内情報は含まれていません（最初に表示されるのは架空のサンプルです）。読み込んだメールの内容はアップロードされません。
- URL を知っている人なら誰でも開けます。社内だけに限定したい場合は、GitHub の有料プラン（Enterprise）の非公開 Pages が必要です。
- フォントと PDF / Word 書き出しの部品はインターネット上の CDN（Google Fonts、cdnjs）から読み込むため、利用時はインターネット接続が必要です。
